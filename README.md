## About me

I'm a **Full-Stack JavaScript Developer** with **5 years of commercial PHP backend experience**, now building applications with **React, TypeScript, Node.js, and NestJS**.

My background is in **REST APIs, authentication, database design, debugging, and maintaining real business systems**. I'm bringing that foundation into modern full-stack development — from responsive interfaces to backend services and integrations.

- **Backend foundation:** PHP, Laravel, FuelPHP, CodeIgniter, MySQL; APIs, SQL optimization, and legacy refactoring.
- **Current focus:** React + TypeScript frontend development and Node.js/NestJS backend development.
- **Engineering mindset:** Clean, understandable code; reliable integrations; practical testing and continuous learning.
